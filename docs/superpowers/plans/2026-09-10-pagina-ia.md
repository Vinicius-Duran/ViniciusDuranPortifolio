# Página de engenharia de IA — Plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: execute pelo pipeline de issues (`/realizar-tarefas` → `coordenador`), ou, fora dele, com `superpowers:subagent-driven-development` ou `superpowers:executing-plans`. Os passos usam checkbox (`- [ ]`) para acompanhamento.

**Objetivo:** publicar a rota `/ia` do portfólio, que mostra a arquitetura em alto nível do sistema de agentes do autor — pipeline ao vivo, regras, pessoa no circuito, memória e lições — sem citar nome de agente, modelo, ferramenta, arquivo ou projeto.

**Arquitetura:** todo o texto mora em `src/data/ai.js`, protegido por `src/data/ai.test.js`, que reprova termos proibidos e nomes de arquivo. `src/pages/ai/AiPage.jsx` só renderiza; o pipeline é uma timeline do GSAP presa por ScrollTrigger acima de 900px, e abaixo disso (ou com movimento reduzido) as etapas ficam empilhadas com todo o texto à vista.

**Stack:** React 19, React Router 7, Vite 6, GSAP 3.15 (ScrollTrigger, SplitText, DrawSVGPlugin — já registrados em `src/lib/motion.js`), anime.js 4, Vitest 5, ESLint 9.

**Spec:** `docs/superpowers/specs/2026-09-10-pagina-ia-design.md` — leia antes de começar. O plano argumenta a partir dela.

**Todo bloco de código e toda saída esperada deste plano foram executados** no estado exato descrito, antes de serem escritos. Os arquivos inteiros abaixo foram copiados do disco por script depois de passar em lint, testes, build e verificação no navegador — não foram redigitados. Se algo divergir do que o plano diz, **pare e pergunte** em vez de inventar número, texto ou valor.

## Restrições globais

- **A linha do público (spec, seção 3).** Pode aparecer: os papéis (supervisão, coordenação, implementação, revisão, entrega), as regras do sistema, como a pessoa entra no circuito e as lições. Não pode aparecer: nome de agente ou de modelo; nome de ferramenta, plataforma, biblioteca ou serviço; nome de arquivo, label, script, comando ou formato de configuração; nome de projeto, cliente ou organização; número interno de repositório.
- **Nenhum nome de IA** (decisão 3 da spec): o agente de plantão é "agente de supervisão"; o modelo é "modelo principal"; os demais são nomeados pelo papel. Isso vale também para **comentários** em `ai.js`, `AiPage.jsx` e `AiSection.jsx` — o teste lê o arquivo inteiro, fora as linhas de `import`.
- **Todo texto visível da página mora em `src/data/ai.js`.** O JSX só renderiza. E-mail sai de `profile.email` (`contact.test.js` reprova contato digitado no JSX).
- **Animação:** só `transform`, `opacity`, `filter`, `clip-path`, `mask` e o `stroke` do trilho via DrawSVG. Quem esconde para revelar é o JS; nenhum estado inicial de animação no CSS.
- **Pin só em** `(min-width: 901px) and (prefers-reduced-motion: no-preference)`, via `gsap.matchMedia()`.
- **Nada novo em `src/lib/motion.js`** e **nenhuma dependência nova**.
- **Identidade visual inalterada:** Archivo, âmbar sobre carvão, a gramática de montagem (`Frame` como primeiro filho de `.part`). Ênfase por peso e cor no `<em>`, nunca itálico caligráfico.
- **Comandos pela ferramenta PowerShell**, chamando os binários de `node_modules\.bin`. A ferramenta Bash deste ambiente passa por um hook que corrompe a saída de testes e buscas (git pelo Bash funciona). Na raiz do repositório:
  - testes: `& .\node_modules\.bin\vitest.cmd run`
  - lint: `& .\node_modules\.bin\eslint.cmd .`
  - build: `& .\node_modules\.bin\vite.cmd build`
- **Commits** em português, verbo no infinitivo como o histórico (`Adicionar…`, `Dar ao…`), com corpo explicando o porquê. Confira `git log main -5` antes.

````js
const semImports = (src) =>
  src
    .split(/\r?\n/)
    .filter((linha) => !/^\s*import\b/.test(linha))
    .join('\n');

const escapar = (texto) => texto.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');

const strings = (valor, acc = []) => {
  if (typeof valor === 'string') acc.push(valor);
  else if (Array.isArray(valor)) valor.forEach((item) => strings(item, acc));
  else if (valor && typeof valor === 'object') Object.values(valor).forEach((item) => strings(item, acc));
  return acc;
};

      const src = semImports(readFileSync(resolve(arquivo), 'utf8'));
      for (const termo of TERMOS_PROIBIDOS) {
        if (new RegExp(`\\b${escapar(termo)}\\b`, 'i').test(src)) {
          achados.push(`${arquivo} :: ${termo}`);
        }
      }
    }
    expect(achados).toEqual([]);
````

````js
// Prova por mutacao do teste da linha publica: injeta um defeito em ai.js,
// e restaura a copia exata depois.
//   node mutar.mjs termo | arquivo | restaurar
import { readFileSync, writeFileSync, copyFileSync, existsSync, rmSync } from 'node:fs';

const ALVO = 'C:/Users/metae/OneDrive/Documents/dev/ViniciusDuranPortifolio/src/data/ai.js';
const COPIA = `${ALVO}.bak`;
const modo = process.argv[2];

const mutar = (de, para) => {
  if (!existsSync(COPIA)) copyFileSync(ALVO, COPIA);
  const src = readFileSync(COPIA, 'utf8');
  if (!src.includes(de)) throw new Error(`trecho nao encontrado: ${de}`);
  writeFileSync(ALVO, src.replace(de, para), 'utf8');
  console.log(`mutante aplicado: "${de}" -> "${para}"`);
};

if (modo === 'termo') {
  mutar('Um agente de supervisão fica de plantão', 'O Hermes fica de plantão');
} else if (modo === 'arquivo') {
  mutar('deixa por escrito o que fez.', 'deixa por escrito o que fez em IMPLEMENTACAO.md.');
} else if (modo === 'restaurar') {
  copyFileSync(COPIA, ALVO);
  rmSync(COPIA);
  console.log('restaurado');
} else {
  throw new Error('modo: termo | arquivo | restaurar');
}
````

````jsx
/**
 * O pipeline ao vivo. A seção fica presa e a rolagem conduz a tarefa pelo
 * trilho: o traço se desenha até a etapa, o ponto acende, o princípio troca.
 * Na revisão a tarefa é reprovada, volta à implementação e refaz o caminho.
 *
 * Posições são funções, e não números: dependem da largura da janela, e o
 * `invalidateOnRefresh` só recalcula o que foi escrito como função.
 */
const montarPipeline = (secao) => {
  const trilho = secao.querySelector('.aip-rail');
  const vivo = secao.querySelector('.aip-rail-live');
  const marcador = secao.querySelector('.aip-token');
  const selo = secao.querySelector('.aip-token-pr');
  const aviso = secao.querySelector('.aip-rejected');
  const etapas = [...secao.querySelectorAll('.aip-stage')];
  const pontos = etapas.map((etapa) => etapa.querySelector('.aip-stage-fill'));
  const principios = etapas.map((etapa) => etapa.querySelector('.aip-stage-principle'));

  const centro = (indice) => {
    const caixaTrilho = trilho.getBoundingClientRect();
    const caixaPonto = etapas[indice].querySelector('.aip-stage-dot').getBoundingClientRect();
    return caixaPonto.left + caixaPonto.width / 2 - caixaTrilho.left;
  };

  const ate = (indice) =>
    `0% ${(centro(indice) / trilho.getBoundingClientRect().width) * 100}%`;

  gsap.set(principios, { autoAlpha: 0, y: 16 });
  gsap.set(pontos, { scale: 0 });
  gsap.set(aviso, { autoAlpha: 0 });
  gsap.set(selo, { autoAlpha: 0, xPercent: -50, scale: 0.6 });
  gsap.set(marcador, { xPercent: -50 });

  const linha = gsap.timeline({
    defaults: { ease: 'none' },
    scrollTrigger: {
      trigger: secao,
      start: 'top top',
      end: () => `+=${window.innerHeight * 3.2}`,
      pin: true,
      scrub: 0.6,
      anticipatePin: 1,
      invalidateOnRefresh: true,
      // Acima das lições na página: precisa medir antes do pin delas.
      refreshPriority: 2,
    },
  });

  linha
    .set(marcador, { x: () => centro(0) }, 0)
    .set(vivo, { drawSVG: () => ate(0) }, 0)
    .to(pontos[0], { scale: 1, duration: 0.25 }, 0)
    .to(principios[0], { autoAlpha: 1, y: 0, duration: 0.35 }, 0)
    .to({}, { duration: 0.6 });

  const avancar = (de, para) => {
    linha
      .to(principios[de], { autoAlpha: 0, y: -16, duration: 0.3 })
      .to(marcador, { x: () => centro(para), duration: 1 }, '<')
      .to(vivo, { drawSVG: () => ate(para), duration: 1 }, '<')
      .to(pontos[para], { scale: 1, duration: 0.25 }, '>-0.25')
      .to(principios[para], { autoAlpha: 1, y: 0, duration: 0.35 }, '<')
      // Respiro: o princípio fica parado e legível antes da etapa seguinte.
      .to({}, { duration: 0.6 });
  };

  avancar(0, 1);
  avancar(1, IMPLEMENTACAO);
  avancar(IMPLEMENTACAO, REVISAO);

  // A reprovação: o aviso acende, a tarefa volta e o traço recolhe junto.
  linha
    .to(aviso, { autoAlpha: 1, duration: 0.25 })
    .to(marcador, { x: () => centro(IMPLEMENTACAO), duration: 0.8 })
    .to(vivo, { drawSVG: () => ate(IMPLEMENTACAO), duration: 0.8 }, '<')
    .to(pontos[REVISAO], { scale: 0, duration: 0.2 }, '<')
    .to({}, { duration: 0.4 })
    .to(aviso, { autoAlpha: 0, duration: 0.25 })
    .to(marcador, { x: () => centro(REVISAO), duration: 0.8 }, '<')
    .to(vivo, { drawSVG: () => ate(REVISAO), duration: 0.8 }, '<')
    .to(pontos[REVISAO], { scale: 1, duration: 0.2 }, '>-0.2')
    .to({}, { duration: 0.4 });

  avancar(REVISAO, 4);
  linha.to(selo, { autoAlpha: 1, scale: 1, duration: 0.3 }, '<');

  return linha;
};
````
